---------------------Queues-----------------------------------------------------

-Queue is data structure based on FIFO( First Come First out)

Use Cases-  Background task
          - file uploading
          -printing/ Task processing

 -queue can be implement two way using array and linked list but using array is not  ideal because in array queue implimentation reindexing of array happen.
 
 array method- 
     -push for add at last and shift for remove from front.
     -unshift for add at first and pop for remove from last.

enqueue- add to queue.
dequeue- remove from queue
