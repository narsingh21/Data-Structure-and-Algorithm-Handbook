A comprehensive collection of data structures and algorithms implemented in JavaScript. Perfect for learning, practice, and interview preparation.

## 📚 Contents

### Data Structures

- **Linked List** - Singly and doubly linked list implementations
- **Stack** - LIFO data structure
- **Queue** - FIFO data structure
- **Priority Queue** - Queue with priority-based processing
- **Heap** - Min/Max heap implementation
- **Tree** - Binary Search Tree (BST) and traversal algorithms

### Sorting Algorithms

- Bubble Sort
- Selection Sort
- Insertion Sort
- Quick Sort
- Radix Sort

### Practice Questions

- GCD/LCM calculations
- Pair sum problems
- Breadth-First Search
- Tree traversals (In-order, Pre-order, Post-order)
- Second highest element

## 🚀 Getting Started

### Prerequisites

- Node.js (v12 or higher)
- npm

### Installation

```bash
# Clone the repository
git clone https://github.com/developer-notes/data-structures-algorithms-handbook.git

# Navigate to the project directory
cd data-structures-algorithms-handbook

# Install dependencies
npm install
```

### Usage

```bash
# Run sorting examples
node sorting/bubble-sort.js
node sorting/quick-sort.js

# Run linked list examples
node linked-list/singly-link-list.js
node linked-list/doubly-link-list.js

# Run tree examples
node tree/bst.js

# Import in your project
const { LinkedList } = require('./linked-list/singly-link-list.js');
```
