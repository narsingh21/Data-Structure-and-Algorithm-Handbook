--------------------------------HEAP-----------------------------------

-Heap are data structure similar like tree.

Binary Heap: binary heap is similar like binary search tree with some more properties. 
             It can have at most two nodes.
             binary heap is compact as much as possible. All the children of node full as they can be and left child are filled first.
             Sibiling is not required any min max relation.
  -types:
   1) Max binary heap where the root node value greater then child nodes. 
   2) Min binary heap where the root node value is lesser then child nodes.

  Representation: binary heap can be represent with list. Start with root with o index and store level by level also the child node should be at 2n+1 where n is parent node index. And parnet at (n-1)/2 where n is child node index.
